# Learning Resources

This collection of resources will help you level up your development skills. Whether you're new to programming or looking to master specific tools, these interactive tutorials and references will accelerate your learning.

## 🖥️ Terminal & Command Line

### Interactive Learning
- **[Terminus Game](https://web.mit.edu/mprat/Public/web/Terminus/Web/main.html)** - Learn Bash commands through an engaging terminal-based adventure game
- **[Command Line Challenge](https://cmdchallenge.com/)** - Practice common command line tasks with instant feedback
- **[Linux Journey](https://linuxjourney.com/)** - Comprehensive guide to Linux fundamentals

### Reference & Cheat Sheets
- **[Bash Manual](https://www.gnu.org/software/bash/manual/)** - Official Bash documentation
- **[Command Line Cheat Sheet](https://www.git-tower.com/blog/command-line-cheat-sheet/)** - Quick reference for common commands

💡 **Pro Tips:**
- Set aside 15-30 minutes daily for learning
- Practice coding concepts immediately after learning them
- Join developer communities (Discord, Reddit, Stack Overflow)
- Build projects to apply what you've learned
- Don't try to learn everything at once - focus on one topic at a time
